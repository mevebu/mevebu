# Convert tools

15 tools in this category, all running in the browser with no upload and no account.
Back to [all categories](../../README.md#whats-inside).

| Tool | What it does | Route |
| --- | --- | --- |
| Base64 | Turn text into Base64 and back. | `#/convert/base64` |
| URL Encoder | Percent-encode or decode a value. | `#/convert/url-encoder` |
| Case Converter | Change text between letter cases. | `#/convert/case-converter` |
| Image Converter | Convert images to another format, in batch. | `#/convert/image-converter` |
| Favicon Converter | Turn one image into a full favicon set. | `#/convert/favicon-converter` |
| Image to PDF | Turn images into one PDF. | `#/convert/image-to-pdf` |
| PDF to Image | Render every page as a PNG or JPEG. | `#/convert/pdf-to-image` |
| PDF Merge | Join several PDFs into one. | `#/convert/pdf-merge` |
| PDF Split | Cut one PDF into parts. | `#/convert/pdf-split` |
| PDF to Text | Copy the text out of a PDF. | `#/convert/pdf-to-text` |
| PDF Page Organizer | Reorder, rotate and delete pages. | `#/convert/pdf-organizer` |
| Text to PDF | Turn plain text into a clean PDF. | `#/convert/text-to-pdf` |
| SVG to PNG | Render an SVG at any pixel size. | `#/convert/svg-to-png` |
| Audio Converter | Convert audio to WAV. | `#/convert/audio-converter` |
| Video Converter | Convert a video to WebM. | `#/convert/video-converter` |
